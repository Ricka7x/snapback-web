Deeplinks Reference

Supported apps and what to enter in the deeplink field for each one.

How it works. When you restore a workspace, Snapback fires the deeplink for each app window in that workspace. The app must be running or installed for the link to work. Only apps listed below are supported. If yours isn't here, let us know and we'll look into adding it.

Terminals

Terminals support two input types: a folder path to navigate to, or a shell command to run.

TerminaliTerm2WezTermKittyGhostty
Navigate to a folder~/Projects/my-app

Type a path starting with / or ~. Snapback runs cd to that directory when the workspace is restored.

Run a commandbun dev

Enter any shell command that isn't a bare path. It runs in the terminal window.

Code Editors

VS Code and Cursor use a URL scheme to reopen a project folder. Zed, Sublime Text, and Xcode take a plain folder or file path.

VS CodeCursorZedSublime TextXcode
VS Code or Cursor: project folder URLvscode://file//Users/you/Projects/my-app

Use vscode:// for VS Code or cursor:// for Cursor, followed by the absolute path. Snapback picks the right scheme automatically.

Click the folder icon to browse instead of typing the path.
Zed, Sublime Text, or Xcode: folder or file path~/Projects/my-app

Type the path to the folder or project file. For Xcode, point to the .xcodeproj or .xcworkspace file.

Click the folder icon to browse instead of typing the path.

Browsers

Any http or https URL opens in the browser that was captured in the workspace.

SafariChromeFirefoxArcBraveEdgeDuckDuckGoZen
Paste any URLhttps://github.com/myorg/myrepo

Snapback checks whether the browser window already shows that domain. If it does, nothing happens. If not, it opens the URL.

Local dev servershttp://localhost:3000

http:// URLs work too. Useful for restoring a local dev server tab alongside your terminal and editor.

Design

Figma takes its web URL directly. Affinity apps take the path to a local file.

FigmaAffinity
Figma: paste the file or project URLhttps://www.figma.com/file/abc123/My-Design

Copy the URL from your browser while the file is open and paste it directly.

Affinity: path to the local file~/Documents/design.afdesign

Type the path to your .afdesign, .afphoto, or .afpub file.

Click the folder icon to browse instead of typing the path.

Notes & Knowledge

Bear and Obsidian each expose a URL scheme to open a specific note or vault.

BearObsidian
Bear: note linkbear://x-callback-url/open-note?id=ABC123

In Bear, right-click a note and choose Copy Note Link. Paste the bear:// URL directly.

Obsidian: vault and fileobsidian://open?vault=MyVault&file=note

Use the Obsidian URI scheme to open a specific vault and file. You can find these from Obsidian's Copy Obsidian URL command.

Collaboration & Productivity

These apps accept both their HTTPS URLs and native URL schemes. Paste the link from your browser or the app.

SlackZoomMicrosoft TeamsNotionLinearDiscord
Slack, Zoom, Teams, Notion, or Linear URLhttps://app.slack.com/client/T0123/C0456

Copy the channel, meeting, page, or issue link from the address bar or Share in the app. Snapback opens it directly in the desktop app.

Discord channel or server URLhttps://discord.com/channels/123456789/987654321

Right-click any channel and choose Copy Link, or copy the URL from Discord in a browser. Snapback automatically converts it to the discord:// scheme so it opens in the desktop app.

Git Clients

GitHub Desktop and SourceTree reopen to a specific local repository.

GitHub DesktopSourceTree
Path to the repository folder~/Projects/myrepo

Type the path to the repository folder.

Click the folder icon to browse instead of typing the path.

Finder

Reopen a Finder window to a specific folder.

Finder
Folder URLfile:///Users/you/Projects/my-app

Use a file:// URL with the absolute path to the folder.

Click the folder icon to browse. Snapback fills in the URL automatically.

App not listed or something not working? Let us know and we'll look into adding support.
